# Model Card for Security Scanner LoRA

A fine-tuned Mistral-7B-Instruct-v0.3 model with LoRA adapters trained on synthetic security scanner data for zero-trust deterministic analysis of system security findings.

## Model Details

### Model Description

This model is a fine-tuned Mistral-7B-Instruct-v0.3 with LoRA adapters specifically trained for security intelligence analysis. It provides deterministic, local-only analysis of security scanner findings without requiring external API calls, ensuring zero-trust operation within trusted infrastructure boundaries.

The model serves as an "analyst agent" in the sys-scan-graph security scanner, performing:

- Security finding summarization and correlation analysis
- Threat triage and prioritization
- Rule refinement based on observed patterns
- Deterministic reasoning over cyclical graph execution

- **Developed by:** Joseph Mazzini
- **Model type:** Large Language Model with LoRA fine-tuning
- **Language(s) (NLP):** English
- **License:** Apache 2.0
- **Finetuned from model:** mistralai/Mistral-7B-Instruct-v0.3

### Model Sources

- **Repository:** <https://github.com/J-mazz/sys-scan-agent-MLops>
- **Base Model:** <https://huggingface.co/mistralai/Mistral-7B-Instruct-v0.3>

## Uses

### Direct Use

This model provides local, deterministic analysis of security scanner findings within the sys-scan-graph security scanner. It operates without external API calls, ensuring zero-trust operation where all analysis happens within trusted infrastructure boundaries.

**Primary Functions:**

- **Security Finding Summarization**: Converts raw scanner outputs into structured, actionable summaries
- **Threat Correlation**: Identifies relationships between different security findings to reveal attack patterns
- **Risk Assessment**: Provides severity scoring and prioritization of security issues
- **Rule Refinement**: Suggests improvements to detection rules based on observed patterns

### Downstream Use

The model serves as the intelligence layer in automated security scanning pipelines, providing:

- Real-time analysis of system security posture
- Automated incident response recommendations
- Continuous learning from scanner outputs to improve detection accuracy
- Integration with existing security monitoring and alerting systems

### Out-of-Scope Use

This model is specifically trained for security scanner data analysis and should not be used for:

- General-purpose text generation or conversation
- Analysis of non-security related data
- Real-time threat hunting outside of scanner output analysis
- Direct interaction with untrusted external systems

## How to Get Started with the Model

This model is designed to be used within the sys-scan-graph security scanner framework. For integration:

```python
from sys_scan_graph_agent.providers.local_mistral_provider import LocalMistralLLMProvider

# Initialize the provider (automatically loads LoRA adapters)
provider = LocalMistralLLMProvider()

# Use for security analysis
summaries, metadata = provider.summarize(
    reductions=scanner_reductions,
    correlations=security_correlations,
    actions=response_actions
)
```

For the complete synthetic data pipeline and training framework, see: <https://github.com/J-mazz/sys-scan-agent-MLops>

## Training Details

### Training Data

The model was trained on a comprehensive synthetic dataset generated by a specialized security scanner data pipeline available at <https://github.com/J-mazz/sys-scan-agent-MLops>. This pipeline creates realistic security scanner findings across multiple categories:

**Synthetic Data Pipeline Features:**

- **Multi-Producer Architecture**: Generates findings from 10+ scanner types including processes, network connections, kernel parameters, kernel modules, file permissions (SUID/SGID, world-writable), IOC patterns, MAC status, DNS telemetry, and endpoint behavior analytics
- **Correlation Analysis**: Advanced correlation producers that analyze relationships between different scanner findings to identify attack patterns and threat chains
- **Quality Verification**: Multi-stage verification system with schema validation, coherence checking, realism assessment, diversity analysis, and abundance control
- **Ground Truth Schema**: Structured JSON schema ensuring consistent data format for model training and evaluation

**Dataset Characteristics:**

- 2.5M+ synthetic security scanner findings with realistic metadata
- Balanced distribution across severity levels (info, low, medium, high, critical)
- Cross-signal correlations representing real-world attack patterns
- Deterministic generation ensuring reproducible training data

The synthetic approach ensures zero-trust operation by eliminating external data dependencies while maintaining training data quality and diversity.
